## 1. 現状理解（実行者への文脈共有）

### 1.1 アプリの概要

スマートフォンを主対象とした1人用3D卓球ゲーム。バックエンドを持たない静的PWAで、GitHub Pages（<https://sitar-sitar.github.io/sitar/>）に `table-tennis/dist/` を公開している。ローカル開発は Vite（ポート3038）。

処理の流れ:

1. `index.html` が `src/main.ts` を module として読み込み、`Ui` / `Game` / `Renderer` / `InputController` / `Feedback` を生成して結線する。
2. `Game.start()` が `requestAnimationFrame` ループを開始する。ループは固定ステップ（`FIXED_STEP` = 1/240秒）で `Game.tick()` を最大12回まで回し、最後に `Renderer.render()` を呼ぶ。
3. `InputController` が Pointer Events を速度サンプリングし、フリック（`Flick`）と横位置を `Game` へ通知する。
4. `Game` がサーブ解の探索（`physics.solveServe`）、打球生成（`makeShot`）、相手AI（`aiThink` / `aiHit`）、バウンド判定と得点（`judgeBounce` / `point`）を行う。
5. `Renderer` が `Game.getRenderScene()` の戻り値（`RenderScene`）だけを入力として、床・台・ネット・相手・ボール・プレイヤーラケットを2D Canvasへ透視投影で描く。
6. `Ui` が DOM（スコア・ラリー数・サーブ選択・オーバーレイ）を更新する。
